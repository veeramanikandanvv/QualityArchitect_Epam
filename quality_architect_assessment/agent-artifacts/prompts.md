# Agent Workflow Prompts

1. Inspect assessment and repository Parts docs/backend serializers/frontend pages/existing tests.
2. Create requirement-to-test traceability.
3. Generate positive, negative, boundary, permission and relational tests.
4. Generate env-configurable pytest/requests tests.
5. Generate Playwright tests with role-based selectors, traces, screenshots and video.
6. Review assumptions, selectors and endpoint paths against the deployed instance.
7. Run tests, document failures/fixes and preserve logs.
