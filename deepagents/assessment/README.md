# QA Assessment

This directory is the canonical home for QA assessment requirements, test design, automation, and evidence.

## Layout

- `requirements/` — UI and API acceptance criteria
- `test-design/` — manual test scenarios
- `automation/playwright/` — browser and Playwright API checks
- `automation/api/` — Python API checks
- `artifacts/` — prompts, reports, and execution evidence

The legacy `quality_architect_assessment/` directory is being replaced by this structure. Do not add new assessment material to the legacy path.
