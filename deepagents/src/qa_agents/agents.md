# Specialist delegation contract

The supervisor delegates in this order:

1. `requirements_analyst`
2. `ui_test_designer` and `api_test_designer`
3. `api_automation` and `ui_automation`
4. `review_evidence`

Every specialist must:

- distinguish source-supported facts from assumptions;
- preserve test IDs and traceability;
- include explicit expected results and assertions;
- avoid claiming execution without logs;
- identify environment prerequisites and cleanup.
